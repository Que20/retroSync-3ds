# CIA / FBI QR installation

Added 2026-10-21 at the user's request. The CIA contains the same read-only 1.0.0 application as the 3DSX.
It is built from the ARM ELF, with native code, icon, banner and CA-root RomFS. No forwarder or Homebrew Launcher
installation is required for the CIA launch path. Modern Luma3DS is required for homebrew signatures.

## Identity and permissions

- Title ID: `000400000F7A6300`, private homebrew ID, stable across updates.
- Product code: `CTR-P-RS3D`; application category, installation to SD.
- TMD/ticket version: `1.0.0` (encoded value 1024).
- No NAND access, title installation/management privilege or backdoor SVC in the application.
- Filesystem permissions: DirectSdmc / DirectSdmcWrite for settings and future user-managed files.
- Services: APT:U, ac:u, cfg:u, fs:USER, gsp::Gpu, gsp::Lcd, hid:USER, ndm:u, ptm:u, soc:U.
- 64 MiB application mode, 64 KiB main stack, New 3DS 804 MHz / L2 cache; SMDH marks New 3DS.

The RSF is `assets/retrosync.rsf`. Process priority is RSF 16, which makerom encodes as kernel priority 48.
Keep title identity consistent for upgrades; check the displayed title in FBI rather than overwriting an unrelated title.

  its README/BUILDING, RSF parser, version handling and CIA/NCCH generation were inspected.
- [bannertool](https://github.com/carstene1ns/3ds-bannertool/tree/734d33be79fd3f8c29c6296158f06ac7c5ca9dcb), v1.2.3.
- [FBI](https://github.com/Steveice10/FBI/tree/ec259153e25fc77ee999b8caadac7e73d2e5e41a): README,
  `source/fbi/remoteinstall.c`, and `servefiles` confirm direct URL/QR installs over local HTTP.
- [FBI buildtools RSF reference](https://github.com/Steveice10/buildtools/blob/b7043ff1854be48ef0d055bba81b0a69a5bc892f/3ds/template.rsf).
  RetroSync's RSF is independently scoped to its required services/SD access; it does not inherit FBI's management permissions.

`scripts/bootstrap-cia-tools.sh` builds these tools locally, without system-wide installation. Two small source fixes
are applied reproducibly in ignored build directories:

1. makerom's title-version enum collides with its own `VER_MINOR=19` macro. Title indices are renamed `TITLE_VER_*`
   to prevent an out-of-bounds title-version index and preserve the requested 1.0.0 metadata.
2. bannertool's initialized variable-length padding array is replaced by a fixed four-byte buffer; its original
   write length remains unchanged. This lets Clang compile it.

These host-tool changes do not alter the application code or grant console permissions. The original graphics are
generated by `scripts/generate-menu-assets.py`; committed PNG/WAV inputs mean builds do not need Pillow.
The optional LAN QR tool uses the pinned Python requirements in `scripts/requirements-packaging.txt`.

## Verification and limits

`scripts/verify-cia.py` checks the CIA header/bounds, one unencrypted content, title ID/version, SHA256 of content and
extended header, ExeFS/RomFS superblock hashes, every ExeFS file hash, required `.code`/icon/banner and embedded CA roots.
The independent upstream ctrtool inspection also checks RomFS integrity levels and reports SD/service access.
Homebrew ticket/TMD/access-descriptor signatures are not Nintendo retail signatures; signature warnings are expected
with these CFW packages and are not claimed as successful retail signature verification.

No real New 3DS/FBI install, HOME menu launch, software keyboard, Wi-Fi request, reboot, update or uninstall has been
performed. Those remain release gates; structural checks cannot establish that service/dependency choices work on hardware.

## QR delivery

`scripts/serve-cia.py --host <computer LAN IPv4>` binds to that address on port 8766, serves only
`/RetroSync3DS.cia`, and writes `dist/RetroSync3DS-FBI-QR.png`. FBI uses **Remote Install → Scan QR Code**.
The payload is a direct URL, not a local file link, ZIP, download page or 3DSX. HEAD and GET provide Content-Length;
other paths receive 404. The source tree, config and tokens are not exposed. HTTP serves only this public homebrew
binary and does not carry RomM credentials. The 3DS must reach the computer on the same LAN, without guest-network
client isolation. Keep the server/computer awake until installation finishes; regenerate if the address changes.

Public distribution now uses GitHub Releases in `Que20/retroSync-3ds`. The committed README QR points to
`https://github.com/Que20/retroSync-3ds/releases/latest/download/RetroSync3DS.cia` and is generated by
`scripts/generate-release-qr.py`. GitHub Actions builds/tests a `v*` tag, verifies the CIA and publishes that exact asset
name plus the install ZIP and SHA256SUMS. The stable latest URL keeps the QR valid across releases.
The LAN server remains an optional development alternative; it is not used by the public README QR.
